# Орынтап — Smart Parking Almaty · MVP-макет

Фронтенд-прототип (React + Vite) приложения «Орынтап»: показывает, как будет выглядеть MVP.
Бэкенда нет — все данные моковые и живут в браузере.

**Демо:** https://zhalgas-seidazym.github.io/oryntap-mvp/

## Что внутри

| Раздел | Что показывает |
| --- | --- |
| **Жоба** (лендинг) | Ценностное предложение, тарифы (7 дней бесплатно → 500 ₸ → 1 000 ₸, бронь 200 ₸), план MVP |
| **Жүргізуші қосымшасы** | Приложение водителя в рамке телефона: карта Алматы с числом свободных мест, фильтры, схема паркинга с зелёными/красными индикаторами, бронирование места (часы + мойка/зарядка), активная бронь с таймером и QR, история броней, профиль и подписка |
| **Серіктес панелі** | Кабинет партнёрского паркинга (B2B): заполненность, брони за день, выручка, комиссия «Орынтап» 10%, живая схема мест, последние брони |

Места на схемах «живут»: каждые ~2.5 с имитируется приезд/уезд машин (как будто данные идут с AI-камер).
Бронь, созданная в приложении водителя, сразу появляется в панели партнёра. Брони и подписка хранятся в `localStorage`; кнопка **Reset** сбрасывает демо.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Структура

```
src/
  data.js                 # мок-данные: паркинги Алматы, тарифы, услуги, генерация мест
  store.jsx               # состояние (useReducer + Context), симуляция камер, брони
  App.jsx                 # верхняя навигация: Жоба / Жүргізуші / Серіктес
  components/
    Landing.jsx           # лендинг
    DriverApp.jsx         # мобильное приложение водителя (все экраны)
    MapView.jsx           # карта (react-leaflet, тайлы CARTO/OSM)
    SpotGrid.jsx          # схема мест с индикаторами
    PartnerDashboard.jsx  # панель партнёра
```

Деплой — GitHub Actions → GitHub Pages при пуше в `main`.
